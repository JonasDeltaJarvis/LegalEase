# LegalEase ⚖️
### Legal language, finally human.

**[Live Demo →](https://your-vercel-url.vercel.app)**

LegalEase is an AI-powered tool that translates any terms and conditions document into plain English. Paste any T&C, get a risk score, illustrated clause breakdown, and the 5 things you actually need to know — in seconds.

---

## The problem
Nobody reads terms and conditions. They are long, written in legal jargon, and designed to be ignored. But agreeing to them without understanding them can lead to real consequences — losing your data, waiving your rights, or being locked into unexpected charges.

## The solution
LegalEase reads them for you. Using the Groq AI API, it analyses every clause, flags the risky ones, and translates everything into plain English with illustrated cards so the results are actually enjoyable to read.

---

## Features
- Risk score — Green / Amber / Red
- Plain English summary
- 5 key points you need to know
- Illustrated clause cards for data, payments, termination, liability, and more
- Fully responsive — works on mobile
- No data stored — your text is never saved

---

## How to run it locally

1. Clone this repo: git clone https://github.com/YOUR_USERNAME/legalease.git

2. Get a free Groq API key at [console.groq.com](https://console.groq.com) — no card needed

3. Open `index.html` and replace `YOUR_GROQ_API_KEY_HERE` with your key

4. Open `index.html` in your browser — done

## Tech stack
- HTML, CSS, JavaScript — no frameworks, no build tools
- [Groq API](https://console.groq.com) — free AI analysis powered by Llama 3
- [Vercel](https://vercel.com) — free hosting
- Google Fonts — Playfair Display + DM Sans
